# Files Overview

`schema.py`

Handles input data validation.
- Ensures entered data is correct and  in required format for prediction.
- Checks for missing or invalid values.

`clean_data.py`

Provides helper functions for data cleaning and pre-processing of raw data.
- Removes duplicates and handles missing values.
- Clean the brand names of car.
- Convert weight feature into categorical feature.
- Extract car brand names from a long text.
